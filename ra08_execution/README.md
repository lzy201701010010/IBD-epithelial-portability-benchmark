# RA08 historical execution code — v1.2.0

Version 1.2.0 adds six frozen author-owned historical scripts, copied byte for byte, with safe configuration and documentation. Source identities are in SAFETY_CHECK_RESULTS.csv. No historical scientific script was executed or imported in preparing this release.

## Scope and use
The scripts implement the historical post-classification external evidence layer: baseline PREDICT donor-level inference and descriptive Elmentaite results. They do not replace the original benchmark or reclassify its program states. PREDICT is secondary within-cohort evidence, Elmentaite is formally NOT_ESTIMABLE, and SP08 has three terminal non-numerical entries.

The historical_layout directory preserves relative ROOT calculations. The included program registry contains gene definitions and rules only. RA08_INPUT_SCHEMA.json describes fields and is not an executable configuration or evidence that a gate passed. No input matrix, barcode, cell/sample/donor table, bridge, protected join, credential, or third-party binary is included.

## Environment
Historical receipts identify Python 3.12.14 and the three top-level versions in requirements-historical.txt. The public original benchmark environment belongs to another phase. No complete binary/transitive lock, current installation or portable runtime has been demonstrated. The local _deps convention is retained in the unmodified code; it does not redistribute dependencies. Obtain dependency packages from their official distributions under their own licences.

## Historical workflow for an authorized independent reconstruction
Read INPUTS_AND_REVIEWER_ROUTE.md and RUNBOOK.md before considering any execution. Reviewers require lawful inputs and historical gate/provenance records. Gate builders write history-dependent records and must not be rerun merely to bypass a failed or missing gate. Several scripts perform input I/O at module import; importing is execution. No automatic runner is supplied.
